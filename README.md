# Rewa Mehta · Product & Experience Designer

> Research-led product designer for healthcare and AI-assisted products. Turning complex, high-stakes workflows into interfaces people trust.

A high-performance portfolio built with **React 19**, **TypeScript**, **Vite**, and **GSAP**, featuring a custom WebGL aperture shader, responsive typography, and deep clinical & AI case studies.

## Tech Stack & Architecture

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Visuals**: Custom WebGL light aperture shader (`canvas.light`) with dynamic chapter lighting
- **Typography**: Inter Tight, Instrument Serif, IBM Plex Mono
- **Motion & Accessibility**: GSAP ScrollTrigger, Lenis smooth scrolling, accessible focus traps, reduced motion toggle (tested WCAG 2.1 AA clean)
- **Deployment**: Automated GitHub Actions workflow to GitHub Pages
